#   * Removed broken pins: cffi==2.0.0, cryptography==46.0.3 (loose

#   * Added timm, einops (DINOv2/VideoMAE support).
#   * Added torchaudio (Wav2Vec2-XLS-R audio backend).
#   * Pinned starlette to match FastAPI 0.110.1 expectation.
#   * Removed unused: google-api-python-client, google-genai, litellm,
#     openai, stripe, tiktoken, pytokens, librt — these are not imported
#     anywhere in the Argus Core backend (verified via grep).
